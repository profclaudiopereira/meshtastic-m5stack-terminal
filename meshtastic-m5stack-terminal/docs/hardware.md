# Hardware checklist

- [ ] Photograph and document DIP switches SW1, SW2, SW3.
- [ ] Confirm Module13.2/CoreS3 Lite pin mappings against official documentation.
- [ ] Check radio power, reset and expander address.
- [ ] Confirm antenna frequency and radio region.
- [ ] Check I2C coexistence between keyboard and module.
- [ ] Confirm CardKB2 operating mode and address.
- [ ] Verify boot logs.
- [ ] Probe SX1262 without transmitting.

Reference: https://docs.m5stack.com/en/module/Module13.2_LoRa-1262
